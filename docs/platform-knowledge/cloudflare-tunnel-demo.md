# 临时公网演示访问

如果老师、同学或队友不在你的电脑旁边，可以把本机运行中的中文开源AI模型社区临时分享出去。这个功能适合课堂答辩、远程演示和小组检查。

## 适合谁使用

这份说明面向演示负责人。普通访问者只需要拿到你发给他的网页链接，不需要安装任何东西。

## 演示负责人怎么分享

1. 先确认本机平台已经启动。
2. 打开前台页面，确认 `http://127.0.0.1:28080` 可以访问。
3. 使用 Cloudflare Tunnel、学校内网穿透工具或其他临时公网工具，把 `http://127.0.0.1:28080` 分享出去。
4. 把生成的 HTTPS 链接发给访问者。

访问者打开链接后，可以像本地一样浏览模型、数据集、Space、排行榜和智能助手。

## 访问者能做什么

- 浏览首页、模型列表、数据集列表和 Space Demo。
- 登录演示账号后上传模型、创建数据集、运行 Demo 或参与快速评测。
- 使用智能助手提问，例如“怎么上传模型”“怎么做快速评测”。

## 演示注意事项

- 临时公网链接只适合短时间展示，不建议长期公开。
- 不要在演示环境里上传真实敏感模型、私有数据或个人密钥。
- 演示结束后关闭临时公网工具，避免本机开发环境继续暴露。

## 常见问题

### 别人打开链接是空白页

先在本机确认 `http://127.0.0.1:28080` 能打开。如果本机都打不开，需要先启动平台。

### 页面能打开但接口报错

说明前台通了，但后端服务可能没启动或网络转发没有包含 `/api` 请求。演示负责人需要检查 Docker 服务状态。

### 链接过一会儿失效

临时公网链接通常不是固定地址。电脑睡眠、网络切换或隧道进程关闭后，链接会失效，需要重新生成。
