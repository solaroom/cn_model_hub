# 搜索资源和使用智能助手

平台提供搜索和智能助手两种入口。搜索适合明确查找资源，智能助手适合用自然语言提问。

## 搜索模型或数据集

1. 打开模型列表或数据集列表。
2. 在搜索框输入关键词。
3. 可以输入模型名、作者、标签、任务类型或格式。
4. 点击结果进入详情页。

常见搜索词：

- `Qwen`
- `中文对话`
- `C-Eval`
- `safetensors`
- `parquet`
- `文本生成`

## 搜索结果怎么看

搜索结果通常会展示：

- 资源名称
- 作者或组织
- 模型、数据集或 Space 类型
- 标签和简介
- 更新时间或相关度

点击资源名称可以进入详情页，继续查看 README、文件、Demo 或评测入口。

## 使用智能助手

1. 打开智能助手页面。
2. 直接输入问题。
3. 等待助手返回答案和来源。
4. 点击答案里的链接进入对应页面。

可以这样问：

- 如何上传模型？
- 如何下载模型文件？
- 怎么参与快速评测？
- MLflow 在模型页怎么看？
- LakeFS 版本记录在哪里？
- 帮我找 Qwen 模型。
- 有没有 C-Eval 数据集？

## 智能助手的答案来源

助手会优先检索平台用户手册，也就是 `docs/platform-knowledge` 下的文档。涉及找模型或数据集时，助手还会调用站内搜索接口，返回真实平台链接。

如果一个问题同时包含“怎么做”和“找资源”，助手会同时使用用户手册和搜索结果。

## 常见问题

### 为什么助手回答里有来源

来源用于告诉你答案来自哪一篇平台手册，方便继续阅读。

### 为什么助手没找到我的模型

模型可能是私有的、还没有被索引，或者关键词不够准确。可以尝试使用模型名、作者名或标签再次搜索。

### 为什么助手回答比较简短

如果大模型整理服务没有配置，助手会使用本地检索结果生成简短答案。平台手册写得越清楚，答案就越稳定。
