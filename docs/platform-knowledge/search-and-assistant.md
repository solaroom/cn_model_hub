# 搜索和智能助手

平台搜索已经接入 Meilisearch。搜索会索引仓库名称、作者、类型、标签、README 摘要和中文模型元数据。Meilisearch 不可用时，平台会回退到数据库搜索，保证基础检索可用。

## 搜索能力

用户可以按关键词搜索模型和数据集，也可以通过智能助手提出更自然的需求，例如：

- 找 Qwen2.5 模型。
- 找 C-Eval 数据集。
- 找中文对话模型。
- 按参数量、格式、标签、作者筛选资源。

搜索结果返回真实平台资源链接，例如 `/models/qwen_demo/qwen2.5-0.5b-instruct` 或 `/datasets/c-eval`。

## 智能助手

智能助手包含两条能力：

- 平台知识问答：只检索 `docs/platform-knowledge` 下的中文知识库文档，并在答案中给出来源。
- 平台资源搜索：调用现有搜索接口查找模型和数据集，返回可点击的平台结果。

如果一个问题既包含平台用法，也包含找资源需求，助手会同时执行知识库检索和搜索接口调用，再用大模型整理回答。

## 模型配置

RAG embedding 模型配置为 `BAAI/bge-small-zh-v1.5`。大模型整理使用配置的 LLM；密钥通过环境变量 `CN_MODEL_HUB_ASSISTANT_LLM_API_KEY` 注入，不写入仓库。
