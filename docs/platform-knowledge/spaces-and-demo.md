# 使用 Space 在线 Demo

Space 是平台里的在线演示入口。用户可以通过 Space 体验模型效果，也可以把自己的模型包装成可访问的 Demo。

## 查看已有 Demo

1. 打开导航栏里的 Space 页面。
2. 浏览已有 Demo 列表。
3. 点击一个 Space 进入详情页。
4. 点击运行或打开 Demo。
5. 在 Demo 页面输入内容，查看模型回复或输出结果。

当前演示重点支持 Qwen2.5 对话 Demo。

## 从模型页进入 Demo

1. 打开目标模型详情页。
2. 查看 Demo 或 Space 区域。
3. 如果已经有关联 Demo，点击进入。
4. 如果页面提供创建入口，可以根据提示创建 Demo。

这样可以从“模型说明”直接跳到“在线体验”，适合课堂展示。

## 创建 Demo 前准备

建议模型仓库包含：

- `README.md`
- `app.py`
- `requirements.txt`
- 模型配置文件
- tokenizer 文件
- 模型权重文件

如果仓库没有自带 `app.py`，平台可能使用内置模板运行支持的模型。当前重点保证 Qwen2.5 类型文本生成模型的演示流程。

## 使用 Demo 时注意

- 首次启动 Demo 可能需要等待依赖安装和模型加载。
- 模型文件越大，启动越慢。
- 如果 Demo 失败，先检查模型文件是否完整。
- 演示环境通常没有 GPU，推理速度可能较慢。

## 常见问题

### Demo 打不开

可能是模型还没启动完成，或运行环境加载失败。稍等后刷新页面，或回到模型页检查文件是否完整。

### Demo 回复很慢

本地 CPU 推理会比较慢，尤其是大模型。课堂演示建议使用小模型或提前启动 Demo。

### 我能上传自己的 Gradio 应用吗

可以尝试在仓库里提供 `app.py` 和 `requirements.txt`。当前平台更适合简单 Demo，复杂服务需要进一步适配运行环境。
