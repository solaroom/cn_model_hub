# 参与快速评测和查看排行榜

快速评测用于在平台内对模型做一次轻量测试，并把结果展示到排行榜。它适合课堂演示和模型版本对比。

## 评测前准备

你需要先有一个可以评测的模型仓库。当前演示重点支持 Qwen2.5 类型的生成式大语言模型。

模型仓库里建议包含：

- `README.md`
- `config.json`
- `generation_config.json`
- `model.safetensors`
- `tokenizer.json`
- `tokenizer_config.json`
- `vocab.json`
- `merges.txt`

如果只是体验流程，可以使用平台已有的 Qwen2.5 演示模型。

## 发起快速评测

1. 登录账号。
2. 打开目标模型页面。
3. 找到评测或快速评测区域。
4. 点击开始快速评测。
5. 等待系统完成 C-Eval 抽样题测试。
6. 查看准确率、正确题数、总题数和评测时间。

评测完成后，结果会和模型仓库、提交版本关联，方便你说明“这个成绩来自哪个模型版本”。

## 查看排行榜

1. 打开导航栏里的排行榜。
2. 进入生成式大语言模型排行榜。
3. 查看模型名称、作者、准确率和评测时间。
4. 点击模型链接可以回到模型详情页。

首页也会展示排行榜前十名，适合答辩时快速展示效果。

## 如何理解评测结果

- 准确率表示模型答对题目的比例。
- 正确题数和总题数说明本次评测规模。
- 当前快速评测偏演示用途，不等同于完整官方 C-Eval 成绩。
- 如果重复评测同一个模型，不同提交版本可能有不同结果。

## 常见问题

### 为什么我的模型不能评测

可能是模型文件不完整、模型类型不受当前快速评测支持，或者 Demo 环境无法加载模型。先确认模型页能正常展示文件和 README。

### 为什么排行榜没有更新

评测可能还没完成，或评测失败。回到模型页查看评测状态和错误提示。

### 可以评测数据集吗

排行榜评测的对象是模型。数据集用于提供评测题目或展示数据资源，不直接作为排行榜参赛对象。
