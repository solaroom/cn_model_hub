# 使用 MLflow 和 LakeFS 查看实验与版本

平台把 MLflow 和 LakeFS 融入模型社区页面，用户不需要先理解底层实现，也可以用它们查看实验记录和文件版本。

## MLflow 能帮用户做什么

MLflow 用来记录模型实验、参数、指标和产物。对用户来说，它最重要的作用是回答这些问题：

- 这个模型有没有关联实验记录？
- 某次评测或训练用了什么参数？
- 指标结果是多少？
- 是否有可以下载或查看的实验产物？

## 在模型页查看 MLflow 信息

1. 打开一个模型详情页。
2. 查看页面中的实验跟踪或 MLflow 区域。
3. 如果模型已经绑定实验记录，可以看到 run、参数、指标或跳转入口。
4. 点击 MLflow 链接可以打开实验详情页面。

课堂展示时，可以用它说明模型结果不是孤立数字，而是有实验过程和指标记录。

## LakeFS 能帮用户做什么

LakeFS 用来管理模型、数据集和 Space 文件的版本。用户在页面上看到的文件树、提交记录和历史版本，背后由 LakeFS 保存。

对用户来说，它最重要的作用是：

- 上传文件后形成一次提交。
- 可以查看仓库文件历史。
- 可以知道当前页面展示的是哪个版本。
- 模型评测结果可以关联到具体提交。

## 在页面里查看文件版本

1. 打开模型或数据集详情页。
2. 进入文件区域，查看当前仓库文件树。
3. 打开提交记录，查看每次上传或修改留下的提交。
4. 需要复现实验时，记录模型仓库和提交版本。

## 推荐使用方式

- 上传模型前，先准备清楚 README 和配置文件。
- 每次重要修改后，写清楚提交说明。
- 做快速评测前，确认当前文件版本就是你要评测的版本。
- 如果使用 MLflow，尽量把评测指标和模型版本对应起来。

## 常见问题

### 普通用户需要登录 LakeFS 吗

通常不需要。大多数文件版本能力已经集成在平台页面里。

### 普通用户需要直接打开 MLflow 吗

只有需要查看实验细节时才需要。平时在模型页看摘要信息就够了。

### 为什么看不到 MLflow 信息

可能这个模型还没有绑定实验记录，或者演示环境没有写入对应 run。
