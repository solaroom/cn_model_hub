# 上传、下载和管理模型与数据集

模型仓库和数据集仓库是平台最核心的资源。模型仓库用于托管模型文件、README 和模型元数据；数据集仓库用于托管评测集、训练语料和说明文档。

## 上传模型

1. 登录账号。
2. 进入模型列表页。
3. 点击新建或上传模型。
4. 填写模型名称、简介、可见性和标签。
5. 创建模型仓库。
6. 上传模型文件和 `README.md`。
7. 回到模型详情页，确认文件树和模型卡片显示正常。

建议上传这些文件：

- `README.md`：介绍模型用途、输入输出、限制和示例。
- `config.json`：模型配置。
- `generation_config.json`：生成参数配置。
- `model.safetensors`：模型权重。
- `tokenizer.json`、`tokenizer_config.json`：分词器文件。
- `vocab.json`、`merges.txt`：词表相关文件。

## 编写模型 README

模型 README 会直接展示在模型页，也会影响搜索和智能助手理解资源。建议包含：

- 模型名称和一句话介绍。
- 适合的任务，例如中文对话、文本生成、分类或嵌入。
- 运行方式和依赖。
- 输入输出示例。
- 训练数据或来源说明。
- 使用限制和注意事项。

## 下载模型

1. 打开模型详情页。
2. 进入文件列表。
3. 点击需要的文件。
4. 使用页面上的下载入口保存文件。

如果模型文件很多，建议优先下载 README、配置文件和 tokenizer，确认结构后再下载大权重文件。

## 上传数据集

1. 登录账号。
2. 进入数据集列表页。
3. 点击新建或上传数据集。
4. 填写数据集名称、简介、可见性和标签。
5. 上传数据文件和 `README.md`。
6. 在数据集详情页确认预览是否正常。

平台适合展示常见结构化数据，例如 parquet、csv、json 和 jsonl。用于评测的数据集应说明题目字段、答案字段和使用方式。

## 下载数据集

1. 打开数据集详情页。
2. 查看 README，确认数据格式和许可说明。
3. 在文件列表中选择需要的文件。
4. 点击下载。

## 设置公开或私有

创建资源时可以选择公开或私有。公开资源可以被其他用户浏览和搜索；私有资源只对有权限的用户可见。

课堂演示通常建议使用公开资源，方便老师和同学直接打开链接查看。

## 常见问题

### 上传后页面没有显示模型说明

确认仓库根目录里有 `README.md`，文件名大小写建议保持标准写法。

### 文件上传失败怎么办

检查文件大小、网络状态和登录状态。大文件上传失败时，可以先上传 README 和配置文件，再分批上传权重。

### 搜索不到刚上传的资源

搜索索引可能还没刷新。可以稍等后重试，或直接通过个人主页进入资源。
