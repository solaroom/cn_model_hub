# 模型和数据集

模型仓库用于托管模型文件、配置文件、tokenizer、README 和模型元数据。当前重点演示 Hugging Face Transformers 类型模型，尤其是 Qwen2.5-0.5B-Instruct。

## 模型卡片

模型页会读取仓库 README 和中文模型元数据，展示模型简介、模型类型、参数量、上下文长度、框架、标签、文件列表、提交信息、Demo 和评测入口。Qwen2.5-0.5B-Instruct 的模型卡片说明了它是经过指令调优的因果语言模型，参数数量约 0.49B，支持中文和多语言对话。

## 模型上传

用户可以新建模型仓库并上传文件。模型文件进入平台存储后，可以在模型页查看文件树和 README。大文件使用对象存储保存，仓库提交由平台记录，便于后续下载、展示、Demo 和评测。

## 数据集管理

数据集仓库用于托管评测集或训练语料。当前演示数据集是 C-Eval，平台展示为中文数据集资源，可在数据集页查看 README、文件和基础信息。数据集预览支持常见结构化格式，例如 parquet、csv、json、jsonl。

## 可演示流程

1. 登录演示账号。
2. 打开模型页查看 Qwen2.5-0.5B-Instruct 模型卡片。
3. 打开数据集页查看 C-Eval 数据集。
4. 从模型页创建或进入 Demo。
5. 对模型发起快速评测，并在排行榜查看结果。
