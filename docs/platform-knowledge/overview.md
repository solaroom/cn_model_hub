# 平台概览

中文开源AI模型社区是一个面向中文 AI 开源资源的模型社区平台。当前项目重点支持模型托管、数据集管理、在线 Demo、中文搜索、快速评测、排行榜、MLflow 实验跟踪和站内智能助手。

平台首页展示资源统计、生成式大语言模型排行榜前十名、最新模型/数据集/空间入口。导航栏包含模型、数据集、空间、排行榜和智能助手，适合课堂演示从上传资源到运行 Demo、评测和检索的完整流程。

## 当前演示资源

- 模型：`qwen_demo/qwen2.5-0.5b-instruct`，用于演示 Qwen2.5-0.5B-Instruct 本地模型托管、模型卡片和 Demo。
- 数据集：`c-eval`，用于演示中文评测数据集展示和快速评测。
- 空间：Qwen2.5 对话 Demo，空间页会显示已创建的 Demo，并可以进入在线演示界面。
- 榜单：生成式大语言模型排行榜，按照 C-Eval 20 题快速评测准确率排序，并在首页展示前十名。

## 主要页面

- `/models`：模型列表和中文搜索。
- `/datasets`：数据集列表和中文搜索。
- `/spaces`：在线 Demo 列表，可直接进入已创建的 Demo。
- `/leaderboards/generative-llm`：生成式大语言模型排行榜。
- `/assistant`：站内智能助手，可回答平台使用问题，也可以调用搜索找模型或数据集。
