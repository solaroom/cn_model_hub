# 用户使用总览

中文开源AI模型社区是一个面向中文 AI 开源资源的平台。用户可以在这里上传模型、管理数据集、运行在线 Demo、参与快速评测、查看排行榜，并使用智能助手查询平台用法。

## 你可以在平台做什么

- 浏览公开模型、数据集和 Space Demo。
- 登录后上传自己的模型或数据集。
- 给模型编写 README 和中文说明。
- 下载模型文件或数据集文件。
- 对支持的模型发起快速评测。
- 在排行榜查看模型评测结果。
- 查看模型相关的 MLflow 实验信息。
- 通过提交记录了解文件版本变化。
- 向智能助手提问平台使用方法。

## 推荐新用户流程

1. 打开首页，先浏览模型、数据集和排行榜。
2. 登录演示账号或注册自己的账号。
3. 打开一个示例模型，查看 README、文件列表和评测入口。
4. 打开一个示例数据集，查看数据说明和文件预览。
5. 使用智能助手提问，例如“如何上传模型”。
6. 创建自己的模型仓库并上传 README。
7. 上传完整模型文件后，尝试运行 Demo 或参与快速评测。

## 主要页面

- 模型：浏览、搜索、上传和下载模型。
- 数据集：浏览、搜索、上传和预览数据集。
- Space：查看和运行在线 Demo。
- 排行榜：查看快速评测结果。
- 智能助手：询问平台使用方法或查找资源。
- 个人主页：展示用户创建的模型、数据集和 Space。

## 常见问题

### 这个平台和普通网盘有什么区别

平台不只是存文件。它会把模型说明、文件树、提交版本、Demo、评测和排行榜组织在一起，更适合展示 AI 模型项目。

### 我应该先上传什么

建议先上传 `README.md`，把模型或数据集说明写清楚，再上传配置文件和大文件。

### 智能助手能回答什么

智能助手主要回答平台使用问题，也可以帮你查找站内模型和数据集。
